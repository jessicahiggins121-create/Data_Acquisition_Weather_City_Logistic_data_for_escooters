# Data_Acquisition_Weather_City_Logistic_data_for_escooters
Using techniques such as webscraping (BeautifulSoup) and API's (Openweather) to create and build a database that moves from python code to being stored in MySQL. The product is a predictive model on where scooters will end up in a city and how to incentivize being located in the more opportune locations. 

### Goal:
1. Collect data to understand the best opperational locations for e-scooters to be located in each city, and understand thier organic movements
2. Design predictive model on e-scooter user behavior
3. Advise an incentive or logistical solution on how to ensure e-scooters are best placed at all times.

### How
1. Use webscrapping to obtain basic city information, use API to access weather data to understand habits and rate of basic usage
2. Use weather information and city geography to design basic predictive model
3. Use the model to predict on usage and optimal locations.
